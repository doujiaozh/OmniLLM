# OmniLLM

OmniLLM is a Python project.

## Requirements

Python 3.10 or newer and pip.

## Build

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

## Run

```bash
python agent/mcp_agent.py
```

## Project structure

- `agent/`
- `app/`
- `core/`
- `docs/`
- `web/`
